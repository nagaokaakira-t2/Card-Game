# カードゲーム(仮)

ブラウザで遊べる 1vs1 対戦カードゲーム。`index.html` を開くと相手を選ぶ
画面が出るので、**CPU対戦(かんたん)** か **AI対戦(強め)** を選んでプレイできます。

## 属性

- **4属性すくみ**: 火・水・風・土(仮称)。隣接属性に強く逆隣に弱い循環関係で、
  有利/不利は**ダメージ2倍/0.5倍**。
- **天・冥**: 4属性とは無関係の特殊属性。デメリットを持つ代わりに他属性より
  強力な、玄人向けの枠。

## カード

- 種類: **クリーチャー** / **特殊効果** の2種
- 枚数: 6属性(火・水・風・土・天・冥)× 各30種類 = **180種類**
- 特性【唯一】: このマークが付いたカードはデッキに1枚まで。
- カードデータは `data/gamedata.json` にすべて格納(名前・属性・コスト・
  攻撃力/体力・効果テキストを自動生成でバランス調整済み)。

## 対戦相手モード

- **CPU対戦(かんたん)**: 出せる手札をランダムに出し、攻撃も無作為に行う。
- **AI対戦(強め)**: コストの高いカードを優先的に展開し、属性有利や
  とどめが取れる攻撃を優先する。HPが半分を切ると回復の能力を使う。

## デッキ / 場

- デッキ枚数: 50枚(起動時に180種類のプールからランダム構築。【唯一】は1枚のみ)
- 場のクリーチャー: 最大5体
- 召喚酔い: 召喚したクリーチャーは**次のターンから**行動可能
- 攻撃: 1ターン1回、**相手クリーチャーを対象**にする
- 直接攻撃: 相手の場にクリーチャーが**1体もいない場合のみ**、プレイヤーへの
  直接攻撃が可能

## 光(コスト)

- 毎ターン確定で **5** 配布(能力「豊穣の加護」でプラス1)
- 光が切れると、光を使うカードは一切使用不可
- 光を増やす手段: 基本は特殊効果カードのみ。【唯一】特性を持つ一部クリーチャー
  だけが例外的に増やせる(データ上に効果テキストとして反映済み)

## プレイヤー

- HP: 基本 **120**
- 能力: コスト制、合計最大 **13**。起動時にランダムで自動選択されます。
  - パッシブ(常時効果): やや高コスト。9種類実装(HP増加、光増加、属性強化など)
  - アクティブ(発動効果): 1ゲーム1回、光を消費して発動。6種類実装
    (回復、全体ダメージ、ドロー、シールドなど)
- 勝敗: プレイヤーのHPが0になった時点で決着

## ターンの流れ

1. 光配布
2. ドロー(手札が5枚未満なら5枚になるまで引く。5枚以上なら1枚だけ引く)
3. 行動(カードプレイ・攻撃・アクティブ能力の使用)
4. ターン終了ボタン → 相手(CPU/AI)のターンが自動で進む

## 実装状況

**動いているもの**
- カード180種・プレイヤー能力の自動生成データ
- デッキのランダム構築、手札管理、光管理、ドロー処理
- クリーチャーの召喚(召喚酔いあり)と、属性相性を反映した戦闘
- 相手の場が空の場合のみ有効な直接攻撃、勝敗判定
- プレイヤー能力(パッシブ/アクティブ)の自動選択と一部効果の発動

## リポジトリ構成

ファイル名は固定し、ファイルの数を増やさない構成にしています。

```
card-game/
├── README.md
├── index.html          # エントリーポイント(モード選択画面を含む)
├── css/
│   └── style.css       # 見た目
├── js/
│   └── game.js         # ゲームロジック一式(CPU/AIの思考ルーチンを含む)
└── data/
    └── gamedata.json    # カード180種+プレイヤー能力のマスターデータ
```

### 更新してもキャッシュが残らないようにする方法

ファイル名は変えず、**URLの末尾のクエリ文字列(`?v=数字`)だけ**を上げます。

- `css/style.css` を更新したら → `index.html` 内の
  `<link rel="stylesheet" href="css/style.css?v=1" />` の数字を `?v=2` に。
- `js/game.js` を更新したら → `index.html` 内の
  `<script src="js/game.js?v=1"></script>` の数字を `?v=2` に。
- `data/gamedata.json` を更新したら → `js/game.js` 先頭にある
  `const DATA_VERSION = 1;` の数字を `2` に(自動的に `?v=2` で読み込まれます)。

ファイルのリネームは不要で、この3箇所の数字を上げるだけで済みます。
